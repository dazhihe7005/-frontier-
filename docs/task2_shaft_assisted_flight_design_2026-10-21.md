# 任务二竖井辅助驾驶完整方案

日期：2026-10-21
状态：实施前评审稿；本文记录已确认的控制口径，尚未修改飞行控制代码
适用工程：`/home/nuc/frontier-upload`

## 1. 方案结论

任务二由原来的“自动下降、自动探底、自动返航”改为**竖井共享控制/辅助驾驶模式**：

- 飞手只负责上升、下降和停止意图；
- 系统负责 XY 定位、井筒居中、主动避障和 Yaw 锁定；
- 不再自动决定下井、返航和任务完成；
- 不使用完整 SUPER Planner，不生成目标点、A* 路径、安全走廊或多项式飞行轨迹；
- XY 使用 MID360S + FAST-LIO2 作为定位源，同时使用雷达点云识别井壁和局部障碍；
- 无人机中心到障碍表面的硬安全距离为 **1.0 m**；按当前约 0.3 m 的机体等效半径计算，机体外缘理论余量约 0.7 m；
- 距离进入 1.0 m 后必须主动横移远离障碍，不能只悬停等待；
- 下视激光通过 PX4 TELEM3 获取，量程 0.3～8.0 m，只负责底部检测和下降保护；
- RC 或雷达完全失联时，禁止继续下降，改用标定悬停推力，并仅在一个有上限的短时间窗口内维持 XY 避障，不沿用最后一次飞手下降指令。

## 2. 明确不做的功能

任务二不再包含：

- 自动下降到井底；
- 根据深度自动控制任务进度；
- 检测到底部后自动返航至井口；
- 自动判定任务完成；
- 垂直位置保持；
- 垂直匀速控制；
- 2.2 m/s 软件闭环限速；
- SUPER 的全局/局部目标导航；
- 由 XY 或 Yaw 摇杆误动作触发任务退出。

原 `ShaftMission` 的 `DESCENDING → RETURNING → COMPLETE` 自动任务状态机不再作为实际飞行控制源。历史代码和仿真证据可保留用于回归对比，但不能与新的辅助驾驶控制器同时拥有 PX4 指令权。

## 3. 控制权分配

| 控制量或输入 | 任务二正常模式下的控制权 | 行为 |
| --- | --- | --- |
| Z 方向 | 飞手 | 油门杆映射为垂直推力或垂直加速度意图 |
| XY 方向 | 辅助控制器 | 自动居中、避障、主动脱离障碍 |
| Yaw | 辅助控制器 | 进入任务二时捕获当前 Yaw，之后锁定 |
| Roll/Pitch 摇杆 | 无直接控制权 | 正常模式忽略并记录，不取消避障 |
| Yaw 摇杆 | 无直接控制权 | 正常模式忽略并记录，不解除 Yaw 锁定 |
| 下视激光保护 | 安全层 | 底部确认后可以覆盖飞手继续下降指令 |
| 任务退出 | 独立模式开关 | 显式退出或紧急人工接管，必须防抖 |

“误碰摇杆”和“主动接管”必须分开：

- 任务二处于激活状态时，XY/Yaw 摇杆抖动不得退出 OFFBOARD，不得关闭避障；
- 只有独立的任务开关或紧急模式开关可以显式撤销任务二控制权；
- 紧急人工接管始终保留，但飞手主动切走任务二后，系统失去 XY 指令权，避障也无法继续保证；
- 必须确认 PX4 `COM_RC_OVERRIDE` 没有启用 OFFBOARD 摇杆自动接管位，否则正常操作升降杆也可能导致 OFFBOARD 退出。

## 4. 总体数据流

```text
RC 升降杆
    │
    └──→ Z 推力/加速度意图 ─────────────────────┐
                                                │
MID360S + IMU → FAST-LIO2 → XY 位置/速度 ──────┤
                                                │
注册点云 → 局部障碍表示 → 居中 + 避障 Vx/Vy ───┤→ PX4
                                                │
任务二启用瞬间的当前航向 → 固定 Yaw ───────────┤
                                                │
TELEM3 下视激光 → PX4 → MAVLink/MAVROS ────────┘
                         底部锁存与下降保护
```

建议通过 PX4 分轴混合控制实现：

- XY 轴输入速度设定值；
- Z 轴输入飞手产生的加速度/推力意图；
- Yaw 输入固定角度；
- PX4 继续负责姿态、角速度和电机底层控制；
- XY 避障引起机体倾斜时，由 PX4 或明确验证过的混控层补偿竖直升力分量，避免横移时额外掉高。

任何时刻只能有一个节点向 PX4 发布最终控制设定值，禁止旧任务二路由器、新辅助控制器和其他桥接器同时输出。

## 5. XY 感知与局部环境表示

### 5.1 输入

- FAST-LIO2 注册点云；
- FAST-LIO2 XY 位姿和速度；
- 雷达与机体之间经过标定的外参；
- 雷达健康状态、点云时间戳和里程计时间戳。

当前 MID360S 存在安装偏移和俯角，障碍距离必须统一换算为“无人机中心到障碍表面”的距离，不能直接使用雷达原点距离。

### 5.2 点云选择

避障不能只使用无限薄的水平切片。每个控制周期至少应考虑：

- 机体当前高度附近、覆盖完整桨盘和机体高度的点云；
- 根据飞手当前上升/下降意图，在运动方向增加有限的垂直前视区域；
- 井壁、突出岩石、横梁、线缆和局部凸起；
- 未被可靠观测的方向按未知处理，不允许中心控制器主动飞入未知区。

### 5.3 局部距离场

使用局部二维 ESDF 或等价的欧式距离场表示当前截面：

- 每个可飞位置保存到最近障碍的距离；
- 距离梯度给出远离最近障碍的方向；
- 最大净空位置作为局部居中目标；
- 不使用点云坐标平均值作为井筒中心，因为不规则井壁和空洞会拉偏平均值。

完整 ROG-Map 可以不进入任务二核心链路。若复用其局部占据数据结构，也不得引入 SUPER 的目标规划、轨迹状态机和历史轨迹控制。

## 6. XY 居中与避障控制

### 6.1 控制器

采用“局部距离场 + 二维 CBF-QP 安全过滤器”。二维 QP 每周期只求解最终 `Vx/Vy`：

```text
目标：
  尽量接近指向最大净空中心的速度；
  尽量保持与上一周期指令连续。

约束：
  不得继续快速接近障碍；
  进入硬安全距离后必须具有远离障碍的速度分量；
  满足 XY 速度、加速度和倾角上限。
```

### 6.2 距离层级

- **硬安全距离 `d_hard`：1.0 m，已确认。**
- **恢复距离 `d_release`：初始建议 1.2 m，最终通过仿真和低速实机测试整定。**
- **开始减速距离 `d_brake`：必须大于 1.0 m。**

`d_brake` 不能写成固定等于 1.0 m，应至少覆盖：

```text
d_brake = 1.0 m
          + 当前XY速度 × 总延迟
          + 横向制动距离
          + 雷达、外参与定位误差余量
```

因此 1.0 m 是不可主动穿越的硬边界，不是等到到达后才开始反应的边界。

### 6.3 XY 状态

1. `CENTERING`
   - 障碍距离充足；
   - 缓慢趋向局部最大净空中心。

2. `AVOIDING`
   - 进入预测减速范围；
   - 逐渐削弱朝向障碍的速度分量；
   - 居中目标仍是软偏好，安全约束优先。

3. `ESCAPING`
   - 任一可信障碍距离小于或等于 1.0 m；
   - 必须产生远离最危险障碍面的速度分量；
   - 不能以普通悬停代替脱离动作；
   - 直到距离达到恢复阈值后才允许退出。

4. `RECOVERING`
   - 已离开硬边界，但尚未达到恢复距离；
   - 继续保持远离趋势，避免在边界反复横跳。

5. `NO_FEASIBLE_ESCAPE`
   - 多个相反方向障碍同时过近，没有一个横向速度能同时增大所有净空；
   - 禁止继续下降；
   - 使用最大化最小净空的确定性方向；
   - 触发高优先级告警和故障状态，不能声称仍有完整安全保证。

### 6.4 求解失败备份

QP 超时、数值异常或无解时：

- 若在 1.0 m 外：输出受限的保守 XY 指令并告警；
- 若在 1.0 m 内：使用原始点云最近障碍法线生成确定性的远离指令；
- 若相反方向约束物理冲突：转入 `NO_FEASIBLE_ESCAPE`，不能盲目选择一个方向；
- 禁止在危险圈内因为求解失败直接沿用旧指令。

## 7. 垂直控制

### 7.1 正常行为

- 飞手升降杆直接映射为 Z 方向推力或加速度意图；
- 中位对应经过标定的悬停附近推力；
- 不锁定 Z 位置；
- 不执行垂直匀速控制；
- 不将 2.2 m/s 作为软件闭环限制；
- 若系统能获得垂直速度，只用于显示、日志和告警，不参与正常限速。

2.2 m/s 只能写入操作规程，不能标记为软件保证值。直接推力控制下，实际速度仍会受重量、电池、竖井气流、横向倾斜和已有惯性影响。

### 7.2 安全层对 Z 的有限覆盖

只有以下情况允许覆盖正常飞手下降意图：

- 下视激光确认底部；
- 底部距离继续减小且飞手未及时上升；
- RC 失联；
- 雷达/定位失联；
- XY 几何无可行逃逸方向；
- 控制链健康检查失败。

这些覆盖属于防撞保护，不构成自动下井或自动返航。

## 8. Yaw 锁定

- 任务二通过预检查后，捕获当前可信 Yaw 为 `yaw_lock`；
- 任务二激活期间持续发布同一 Yaw 目标；
- Yaw 摇杆输入不修改 `yaw_lock`；
- Yaw 摇杆误动不取消避障、不退出任务；
- 航向估计失效时进入故障状态，不能继续假装已经锁定；
- 重新进入任务二时重新捕获 Yaw，不跨任务沿用旧值。

## 9. 下视激光与 TELEM3

### 9.1 数据链路

正式数据链路为：

```text
下视激光
  → PX4 TELEM3 串口驱动
  → PX4 uORB distance_sensor
  → MAVLink DISTANCE_SENSOR
  → MAVROS sensor_msgs/Range
  → /mine_uav/shaft/bottom_range
  → 底部保护状态机
```

要求：

- TELEM3 由激光驱动独占，不能同时配置成 PX4 MAVLink 通信口；
- PX4 与 NUC 使用其他链路传输 MAVLink；
- 正式输入必须带时间戳、方向、最小/最大量程和当前距离；
- 方向必须验证为下视，PX4/MAVLink 枚举应为 `orientation=25`；
- MAVROS 输出统一使用米；
- 激光只作为底部保护输入，不为了任务二将其融合成全程 Z 定位源；
- 当前工作区记录的实际驱动名称为 `stp23`，实施前必须重新确认当前固件和设备状态。

### 9.2 预飞验证

超过 8 m 时，无回波和传感器失效可能表现相似，因此每次任务前必须进行近距离目标检查：

1. 在 0.3～8.0 m 内放置可靠目标；
2. PX4 `stp23 status` 显示串口、帧计数和有效点正常；
3. PX4 `listener distance_sensor` 能持续得到新样本；
4. NUC/MAVROS 能收到对应的 `sensor_msgs/Range`；
5. 核对 0.5 m、1 m、5 m、接近 8 m 的静态距离；
6. 验证遮挡、超量程、拔线和恢复时的消息行为；
7. 本次上电周期未通过检查时，禁止进入任务二。

### 9.3 底部确认

不能用单个有限值直接触发。可信确认至少需要：

- 消息和传感器时间戳新鲜；
- 距离位于标定后的 0.3～8.0 m 有效范围；
- 连续 2～3 帧有效；
- 帧间跳变和变化方向合理；
- 数据源、方向和设备身份与配置相符。

### 9.4 底部保护状态

1. `NO_BOTTOM`
   - 激光链路已通过预飞检查；
   - 当前无有效目标或目标超过量程；
   - 允许正常人工下降。

2. `BOTTOM_CANDIDATE`
   - 首次收到有效距离；
   - 开始连续帧确认；
   - 尚不因单帧噪声锁存。

3. `BOTTOM_DETECTED`
   - 连续确认通过后立即锁存；
   - 通过地面站、机载蜂鸣器和可用的遥控器反馈提示“发现底部”；
   - 立即禁止进一步增加下降推力；
   - 飞手拉升指令正常通过；
   - 偶发测距丢帧不能解除锁存。

4. `BOTTOM_EMERGENCY`
   - 飞手没有及时上升，且距离继续减小；
   - 完全拒绝下降指令；
   - 自动施加经过台架和实机标定的制动/上升推力；
   - XY 居中和避障继续运行；
   - 持续发出高优先级告警。

底部锁存默认保持到本次任务二退出。若确认是横梁、临时物体或误报，需要显式退出任务二并重新执行进入检查，不能在飞行过程中自动清除锁存后继续下降。

底部紧急阈值和上升推力不能凭经验硬编码，必须根据最不利的 2.2 m/s 操作速度、链路延迟、飞手反应时间、实测制动能力和目标离地余量确定。

## 10. RC、雷达和链路失效

### 10.1 RC 完全失联

已确认策略：

- 不沿用最后一次飞手指令；
- 立即禁止下降；
- Z 改为标定悬停推力；
- 雷达仍健康时，在有上限的短时间窗口内继续 XY 居中和避障；
- 持续告警并等待 RC 恢复或显式故障处置；
- 短时窗口长度必须通过测试确定，不能无限维持。

### 10.2 雷达/FAST-LIO 完全失联

已确认策略：

- 立即禁止下降；
- Z 改为标定悬停推力；
- 只能在有上限的短时间窗口内使用最后一份已验证局部地图和连续受限的 XY 指令；
- 不允许长期使用冻结地图继续飞行；
- 窗口到期后进入 `SENSOR_FAULT`，停止任务推进并请求明确的故障处置；
- 因定位和障碍感知共用雷达链路，不能声称此状态下仍具有完整避障能力。

### 10.3 PX4/MAVROS 或设定值链路失效

- 所有输出必须有严格的时间戳和超时；
- 不允许无限沿用最后一个设定值；
- OFFBOARD 退出必须被任务调度器观察并锁存；
- 重新恢复通信不能自动重新夺回控制权，必须重新进入任务二。

### 10.4 下视激光失效

- 任务前从未通过有效回波检查：禁止进入任务二；
- 任务中在底部锁存后失联：锁存保持，下降权限不能恢复；
- 任务中尚未探测到底部时失联：高优先级告警并禁止继续下降；
- 不把“长时间无有效底部回波”直接当作传感器健康证明。

## 11. 任务状态机

建议的新任务二顶层状态：

```text
DISABLED
   ↓ 显式任务开关
PRECHECK
   ├─失败────────────→ FAULT
   └─通过────────────→ ACTIVE

ACTIVE
   ├─CENTERING
   ├─AVOIDING
   ├─ESCAPING
   ├─RECOVERING
   ├─BOTTOM_DETECTED（可与XY状态叠加）
   └─链路/传感器故障→ SENSOR_FAULT

任意活动状态
   ├─显式退出/接管→ DISABLED
   └─底部继续逼近→ BOTTOM_EMERGENCY
```

不再使用 `DESCENDING`、`RETURNING`、`COMPLETE` 作为任务控制状态。状态消息应能区分正常辅助、主动逃逸、底部锁存、输入丢失和故障。

## 12. 墙面避障验证模式

### 12.1 正式模式不开放直接 XY 控制

正常任务二中，XY/Yaw 摇杆不进入最终控制计算，因此误碰不会取消避障。

### 12.2 专用 `wall_test_mode`

为了验证“飞手给出撞墙方向时，系统是否拒绝危险命令”，可以增加一个默认关闭、只能由专用测试启动文件启用的墙面测试模式：

- XY 摇杆只形成期望横向速度；
- 期望速度仍必须经过距离场和 CBF-QP；
- 最终 XY 控制权始终属于安全层；
- Yaw 摇杆仍不解除锁定；
- 使用明显低于正式参数的 XY 速度、加速度和倾角上限；
- 需要独立软件开关和物理测试确认，不能误入正式任务；
- 紧急人工接管开关始终有效。

这不是“开放绕过避障的 XY 控制权”，而是“向安全过滤器提供一个朝墙的测试意图”。

### 12.3 不以撞上硬墙作为测试目标

正确的验收目标是：朝墙意图在硬边界前被削弱、拒绝或反向，而不是验证撞墙后的结果。

验证主动逃逸更安全的方法：

- 飞机保持低速悬停；
- 使用泡沫板、纸板墙或软网缓慢向飞机靠近；
- 障碍进入阈值后观察飞机是否主动远离；
- 或在仿真中直接插入一个位于 1.0 m 内的障碍；
- 首次实景竖井飞行不故意贴近真实井壁。

## 13. 分级验证计划

### 第一级：纯算法单元测试

使用合成点云和几何环境覆盖：

- 圆形井；
- 椭圆井；
- 偏心和不规则井壁；
- 单侧突出物；
- 多侧同时接近；
- 小于 1.0 m 的初始侵入；
- 无可行横向逃逸的窄通道；
- 点云跳变、空帧、乱序和超时；
- QP 超时和无解。

### 第二级：离线回放/影子模式

- 回放真实或仿真点云；
- 控制器只计算、不向 PX4 发布；
- 对比最近距离、中心位置、状态和期望 Vx/Vy；
- 验证坐标方向、外参、时间戳和障碍法线。

### 第三级：Gazebo PX4 SITL

工作区现有 22 m、45 m 和 500 m 竖井场景可复用，其中 500 m 场景包含不规则井壁和 MID360/FAST-LIO 链路。

测试内容：

- 正常居中升降；
- 虚拟 XY 朝墙意图；
- 墙面突然进入 1.0 m；
- 点云和定位丢失；
- RC 丢失；
- 下视距离首次进入 8 m；
- 激光单帧误报、连续确认、丢帧和断线；
- 底部锁存与紧急上推；
- OFFBOARD 退出后禁止自动重新接管。

### 第四级：拆桨硬件联调

- 检查真实 MID360 外参和方向；
- 检查 TELEM3、`stp23`、uORB 和 MAVROS 测距链；
- 手动移动障碍，确认 Vx/Vy 指令远离障碍；
- 推动所有 RC 摇杆，确认 XY/Yaw 误动不会取消避障；
- 测试独立任务退出和紧急接管开关。

### 第五级：系留/防护区软障碍测试

- 低高度；
- 严格限制 XY 速度和倾角；
- 先让软障碍向飞机移动；
- 再启用 `wall_test_mode` 给出小幅朝墙意图；
- 使用外部测量记录真实最小距离。

### 第六级：真实竖井递进测试

1. 入口附近悬停和居中；
2. 小范围人工升降；
3. 轻微偏心后的自动恢复；
4. 下视激光提示和下降锁存；
5. 更深区段飞行；
6. 全过程不以真实硬墙碰撞作为验证方式。

## 14. 验收标准

### 14.1 控制权

- 任务二激活期间，XY/Yaw 摇杆不能关闭避障；
- 只有独立开关可以退出任务二；
- 任意时刻只有一个 PX4 最终设定值发布者；
- OFFBOARD 退出后不会自动重新夺权。

### 14.2 XY 安全

- 接近 1.0 m 前已经开始减速；
- 在硬边界处不得输出继续指向障碍的速度；
- 小于等于 1.0 m 时，最终 XY 指令具有远离最危险障碍面的分量；
- 达到恢复距离后才回到普通居中；
- QP 异常时不会沿用危险旧指令；
- 雷达/定位超时后不会继续正常任务推进。

### 14.3 下视激光

- 预飞能确认真实新鲜测距；
- 连续 2～3 帧有效后锁存底部；
- 锁存后立即告警并禁止增加下降推力；
- 后续丢帧不会恢复下降权限；
- 飞手上升指令正常通过；
- 飞手不响应且距离继续减小时进入紧急制动/上推；
- 拔线、超量程和无有效点能够在日志中区分或明确暴露为不可区分风险。

### 14.4 失联

- RC 或雷达失联后不沿用最后一次下降命令；
- 自动切换为标定悬停推力；
- XY 仅维持经过验证的短时避障窗口；
- 超过窗口后进入明确故障状态并告警。

### 14.5 日志

必须记录：

- 原始 RC 通道；
- 任务开关和模式；
- 原始及过滤后的点云健康状态；
- FAST-LIO 位姿、速度和状态；
- 最近水平障碍距离及方向；
- 局部中心；
- QP 输入、输出、状态和求解结果；
- 最终 PX4 Vx/Vy、Z 推力/加速度和 Yaw；
- 原始下视激光距离、有效性和时间戳；
- 底部状态机；
- 所有超时、接管、锁存和故障原因。

## 16. 实施范围

最终确认后，实施工作应至少包括：

1. 新增任务二辅助控制器，替换自动下降/返航控制源；
2. 新增或重构 RC 升降意图读取；
3. 新增局部障碍表示、最大净空中心和二维安全过滤器；
4. 新增固定 Yaw 控制；
5. 新增 TELEM3/PX4/MAVROS 下视测距适配与底部保护状态机；
6. 修改任务调度器的任务二状态契约；
7. 增加单一 PX4 指令所有者和模式接管保护；
8. 新增 `wall_test_mode`，默认关闭；
9. 增加单元测试、ROS 集成测试、SITL 故障注入和日志审计工具；
10. 保持生产 `shaft_task_available=false`，直至上述验收完成。

任务一的 SUPER、探索逻辑和现有任务一参数不在本次修改范围内。

## 17. 已知安全边界

- 雷达同时承担定位和障碍感知，属于共同失效源；
- 标定悬停推力不能保证真正定高，只是失联时比沿用下降命令更保守；
- 小于 1.0 m 且多侧障碍约束冲突时，可能不存在任何同时远离全部障碍的 XY 动作；
- 下视激光超过 8 m 时不能提供底部信息；
- 没有垂直速度闭环时，2.2 m/s 不是可证明的实际速度上限；
- 反应式辅助控制器比完整路径规划器简单，但仍可能因坐标、外参、时间同步或传感器错误生成危险指令；
- 任何实机飞行结论必须来自分级验证和飞行日志，不能仅由仿真通过推导。
